## Repository Settings

1. Go to Settings → General
2. Scroll to "Features"
3. Enable:
   - ✅ Issues
   - ✅ Discussions (optional)
   - ✅ Wiki (optional)
   - ✅ Projects (optional)

4. Scroll to "Danger Zone"
5. Make sure repository visibility is set to **Public**
